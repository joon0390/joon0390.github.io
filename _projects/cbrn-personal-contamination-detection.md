## 프로젝트 요약

- 개요: CUSUM 기반 이상 탐지와 다채널 시계열 분류를 결합한 개인 오염 감지 모델 설계
- 기간: 2025.04-
- 데이터: 여러 센서 채널로 구성된 보드 단위의 개인 오염 감지 모듈 시계열 신호
- 기술 스택: CUSUM, MiniRocket, GPSignature, WaveletPCA, Random Forest, Soft Voting, Stacking Ensemble
- 성과(성능): 채널별 반응 차이를 반영한 앙상블 구조로 예측 강건성 향상 (세부 수치는 보안서약상 비공개)

## 문제 정의

화생방 상황에서는 오염 여부를 빠르게 판단하는 것이 중요하지만, 센서 신호는 온도, 습도, 주변 환경, 장비 상태에 따라 쉽게 흔들릴 수 있습니다. 단순히 특정 임계값을 넘었는지만 보는 방식은 실제 환경에서 오탐과 미탐을 만들 가능성이 높습니다.

이 프로젝트는 개인 오염 감지 모듈에서 발생하는 시계열 신호를 바탕으로, 오염 징후를 조기에 탐지한 뒤 해당 구간의 상태를 분류하는 판단 구조를 만드는 것을 목표로 합니다. 핵심은 보드 전체를 하나의 입력으로만 보지 않고, 센서 채널마다 다른 반응 특성을 모델에 반영하는 것이었습니다.

## 데이터와 EDA

데이터는 여러 센서 채널로 구성된 보드에서 수집한 시계열 신호입니다. 같은 보드 안에서도 채널별 반응 속도와 민감도가 다를 수 있어, 모든 채널을 한 번에 입력하는 방식만으로는 특정 채널의 둔한 반응이나 노이즈에 영향을 받을 수 있었습니다.

EDA에서는 다음 질문을 중심으로 데이터를 해석합니다.

- 정상 상태에서도 센서 신호가 얼마나 흔들리는가?
- 오염 이벤트는 순간적인 spike인지, 일정 시간 유지되는 패턴인지?
- 보드 내 채널별 반응 속도와 신호 크기에 차이가 있는가?
- 환경 조건 변화와 실제 오염 신호를 어떻게 분리할 수 있는가?

## 접근 방법

문제를 단순 이진 분류로만 보지 않고, `CUSUM 기반 이상 탐지 + 시계열 분류`의 2단계 구조로 나눴습니다.

### 1. CUSUM 기반 이상 탐지

먼저 정상 상태의 기준선에서 벗어나는 변화가 누적되는지를 CUSUM으로 추적했습니다. 이 단계는 전체 시계열을 바로 분류하는 대신, 오염 가능성이 있는 변화 구간을 빠르게 포착해 다음 분류 단계로 넘기는 역할을 합니다.

### 2. 시계열 분류 모델 비교

CUSUM이 감지한 구간을 대상으로 다음 네 가지 분류기를 구성하고 비교했습니다.

- `MiniRocket`
- `GPSignature`
- `WaveletPCA`
- `Random Forest`

초기에는 보드의 다채널 신호를 한 번에 모델에 입력했습니다. 다만 실제 신호에서는 특정 채널이 민감하게 반응하는 반면 다른 채널은 반응이 늦거나 둔할 수 있었습니다. 하나의 다채널 모델에만 의존하면 이런 채널별 차이가 예측 안정성을 떨어뜨릴 수 있었습니다.

### 3. 채널별 신뢰도 가중 Soft Voting

이를 보완하기 위해 네 분류기 각각에 대해 채널별 단일 모델을 따로 두었습니다. 각 모델이 낸 예측 확률 벡터에서 가장 큰 확률과 두 번째 확률의 차이를 해당 채널의 확신도로 정의했습니다.

확신도가 큰 채널은 해당 구간을 더 분명하게 판단한 것으로 보고 높은 가중치를 부여했습니다. 반대로 반응이 둔하거나 불확실한 채널의 영향은 낮춘 뒤, 채널별 예측을 confidence-weighted soft voting으로 결합했습니다.

### 4. 모델 간 Stacking

채널별 soft voting 구조는 `MiniRocket`, `GPSignature`, `WaveletPCA`, `Random Forest` 각각에 동일하게 적용했습니다. 마지막으로 네 모델의 출력을 다시 스태킹해, 서로 다른 시계열 표현 방식이 포착하는 정보를 결합했습니다.

## 성과(성능)

채널별 반응 차이를 단일 다채널 입력에 묻히지 않게 처리하면서, 일부 채널의 불안정한 신호에 덜 흔들리는 예측 구조를 만들었습니다. 구체적인 성능 수치와 실험 정보는 보안서약상 공개하지 않습니다.

## 느낀점

이 프로젝트에서는 모델을 하나 더 복잡하게 만드는 것보다, 어떤 채널의 판단을 얼마나 믿을지 다루는 일이 더 중요했습니다. 같은 상황에서도 모든 센서가 똑같이 반응하지 않기 때문에, 채널별 예측을 그대로 평균내는 방식보다 각 채널의 확신도를 반영하는 방식이 실제 신호에 더 잘 맞았습니다.

또한 CUSUM으로 변화 구간을 먼저 좁힌 뒤 분류를 수행하면서, 탐지와 분류가 각각 다른 역할을 가져야 한다는 점을 분명히 볼 수 있었습니다. 안전 시스템에서는 단순 정확도뿐 아니라 변화 감지의 시점, 오탐과 미탐, 그리고 예측의 일관성을 함께 고려해야 한다고 느꼈습니다.
